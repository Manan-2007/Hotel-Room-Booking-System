Grand Stay Hotel - Room Booking System
Team: Arshpreet Kaur, Manan Kochhar, Atharv Bains

Compile:  javac *.java
Run (styled GUI):  java HotelGUI
Run (console version):  java Main

Both versions share the same logic (Hotel, Booking, Room, Customer)
and the same saved data file (bookings.txt).

Required features
 1. Display available rooms   - room cards for the chosen dates (green = free, red = booked)
 2. Book a room               - click a card, fill guest details, Book
 3. Store customer details    - name, phone, email, ID proof saved with each booking
 4. Cancel room bookings      - Bookings tab > select > Cancel
 5. Calculate total charges   - live bill: nights x rate + 12% GST, plus a receipt popup
Extras: date-overlap check (no double booking), data saved to bookings.txt.
